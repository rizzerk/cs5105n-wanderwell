# Pocket Reef

> A tiny aquarium, a handful of fish, and a whole little world to build.

**Pocket Reef** is a cozy 2D aquarium game where you care for fish, discover new species, decorate your aquarium, and slowly turn a tiny reef into your own underwater haven.

## Game Genre

**2D Cozy Aquarium Management / Collection Simulation**

The game focuses on:

* Caring for and feeding fish
* Collecting different species
* Decorating and customizing the aquarium
* Earning rewards and purchasing new fish
* Unlocking new content as the aquarium grows

## Activity 1 — Hello World Scene

The first prototype for Pocket Reef is a simple 2D Godot scene containing a `Node2D` root and a `Sprite2D` placeholder. The scene runs successfully as the initial foundation for the game.

* Created the **Pocket Reef** Godot project.
* Created a `Node2D` as the root node.
* Added a `Sprite2D` with a placeholder image.
* Ran the 2D scene successfully.
* Created and initialized the Git repository.
* Added a Godot `.gitignore`.
* Configured Git LFS for large art and audio files.
